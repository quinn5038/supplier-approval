## 三、快速开始（简版）

完整步骤见根目录 `README.md`，这里给最简路径：

```bash
# 1. 主项目环境（Python 3.13）
pip install -r requirements.txt          # FastAPI/Jinja2/Uvicorn/PyYAML

# 2. 配凭证
cp .env.example .env                      # 填 SCPMA_COOKIE / TEXTIN_APP_ID / TEXTIN_SECRET_CODE

# 3. 离线脱敏环境（Python 3.11 + PaddleOCR，详见 offline_desens/README.md）
#    装好后，PADDLE_PYTHON / PADDLE_MODEL_DIR 用环境变量指向即可

# 4. 启动
uvicorn web.app:app --host 0.0.0.0 --port 8000
```

浏览器打开首页 → 更新 Cookie → 点「后台审批」→ 完成后「查看结果」。

## 四、核心亮点速览

1. **离线脱敏（保密合规）**：身份证用 PaddleOCR 本地精确打码，只保留「姓名+有效期限」，证号/住址/头像不出本机。实现见 `offline_desens/idcard_masker.py`。
2. **规则引擎 YAML 化**：准入标准全部落 `rules.yaml`，可读可改可审计。
3. **端到端自动化闭环**：拉取→下载→脱敏→OCR→判定→报告，一键完成，人工只做复核。
4. **可复现可移交**：不绑定个人连接器，版本走 Git，路径/凭据环境变量化。

## 五、移交注意事项

- 身份证脱敏依赖独立 Python 3.11 环境（PaddleOCR 2.9.1 不支持 Python 3.13，需隔离 venv），换机器时按 `offline_desens/README.md` 重建；
- 凭证（`.env`）不入库，接手人需自行填写 Cookie / TextIn / 企查查等密钥；
- 真实供应商数据（`files_cache*/`、`cache_v*.json`、`textin_results.json`、`stage2_results.json` 等）不入库，属敏感数据。
