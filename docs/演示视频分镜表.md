## 录制注意事项

1. **不要暴露真实供应商名**：镜头扫过待办列表时，如果保密员回复涉密，需要后期打码或重新录制虚构数据版本
2. **cookie 过期处理**：录制前确认 cookie 未过期，否则会触发 cookie_expired alert 影响画面
3. **进度条等待时间**：湖北科规已有完整 stage2_results，webui 会直接展示已有结果不重跑流水线（约 2 秒）。如果想让进度条完整跑，先用 `del stage2_results.json` 删除结果文件再录制（但会失去"已有结果直接展示"特性）
4. **演示地址稳定性**：cpolar 免费版 URL 每次重启会变，录制前最后启动一次 cpolar 拿稳定 URL
5. **声音**：建议录制时实时配音，比后期剪辑更自然；如果用字幕，提前在 OBS 配置文字源
