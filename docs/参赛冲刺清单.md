## 六、评委常见问题预演

| 评委问题 | 推荐回答 |
|---|---|
| 为什么不直接调 ICCEC 官方 API？ | 已向公司IT询问，等待回复期间用浏览器模拟方案无缝迁移，规则引擎通用 |
| 财报为什么不直接 OCR？ | 按保密合规要求，未公开披露的财报数据不能发给 AI；改走企查查公查数据（公开信息） |
| 身份证为什么不做 OCR？ | 同上，身份证是敏感证件，按保密员共识仅校验材料上传，详细识别转人工 |
| 脱敏助手精度如何？ | 简化策略：国徽页保留 + 人像页整片打码，宁可多打不可漏打 |
| 如何保证 OCR 不接触原始敏感数据？ | 流水线第 1.5 步自动脱敏，scan_files 优先读脱敏目录，零原始数据泄露路径 |
| 是否依赖个人？ | 完全不依赖——所有凭据从 .env 读取，规则 YAML 化，WebUI 浏览器即用，任何同事都能上手 |
