更新 Cookie
浏览器登录 scpma.iccec.cn → F12 复制 Cookie → 点右上角按钮粘贴
2
后台审批
点某行的「后台审批」，程序在后台跑（下载材料→脱敏→OCR→规则判定），无需停留本页
3
查看结果
跑完后按钮变为蓝色「查看审批结果」，点击进入详情页看审查报告和审批意见

更新 Cookie

1. 浏览器打开 scpma.iccec.cn 并确认已登录
2. F12 → Network → 任选一个请求 → 复制请求头里的 Cookie 值
3. 粘贴到下方输入框（可选填 Authorization 令牌）
